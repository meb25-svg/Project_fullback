Are Offenses Making a Strategic Mistake by Not Utilizing a Fullback?

An Analytics-Based Evaluation of the Fullback Position in the Modern NFL

Introduction

The Question

  • The fullback is a dying position in the NFL
  • Usage has declined significantly over the past decade
  • But is this decline analytically justified?
  • Research Question: Are offenses making a strategic mistake by not utilizing a fullback?

Why It Matters

  • Offensive coordinators make personnel decisions every game
  • If fullbacks provide measurable value, teams leaving them off rosters are losing wins
  • Analytics can help answer this question of should offenses use fullbacks

Data

Data Sources

  • Play-by-Play Data from nflreadr — 2020 to 2024 seasons
  • Participation Data from nflreadr — player-level personnel tracking
  • Position idoffense_positions column (available 2023-2024 only)
  • Fullback id using "1 FB" in offense_personnel string

Key Variables

  • has_fullback — whether a fullback was in the personnel grouping
  • situation_type — goal line, short yardage, or base down
  • Outcome variables: short_yardage_success, goal_line_success, epa
  • Controls: down, yards to go, yard line, defenders in box, WPA, drive metrics

Situation Definitions

  • Goal Line — yardline ≤ 5
  • Short Yardage — 3rd or 4th down with ≤ 2 yards to go
  • Base Down — 1st and 10, or 2nd and 5-10

Methods

Analytical Approach

Three-stage analysis: - Plus/Minus — raw comparison of outcomes with and without fullback - Base Models — logistic and linear regression controlling for situational factors - Random Effects Models — mixed models accounting for individual fullback identity

Base Models

  • Short Yardage & Goal Line → logistic regression (glm, binomial)
  • Base Down → linear regression (lm)
  • Controls selected using Pearson correlation feature selection
  • Ran on full dataset (all NFL teams, 2020-2024)

Random Effects Models

  • Mixed effects models (glmer/lmer) using lme4
  • Random intercept and slope for has_fullback by fullback_id
  • Limited to 2023-2024 (only seasons with position-level data)
  • 15 identified primary fullbacks across teams and seasons

Base Down Results

  • Fullback presence not significant in most base down models

Random Effects Key Finding

  • Most singular fits — individual fullback identity does not drive outcomes
  • The only situation that shows true variation between fullbacks is goal line rush plays
  • The position matters more than the player in most situations

Conclusion

Key Takeaways

  • Fullbacks provide measurable value in short yardage situations
  • It is valuable to have a fullback on roster
  • Individual fullback identity matters most at the goal line
  • Base down value is limited

Limitations

  • Position-level data only available for 2023-2024
  • Only 15 identified fullbacks; limits random effects precision
  • Cannot capture blocking value or play-action threat contributions

Future Work

  • Expand to more seasons as position data becomes available
  • Incorporate tracking data to measure blocking contributions
  • Compare fullback value against tight end in same formations
